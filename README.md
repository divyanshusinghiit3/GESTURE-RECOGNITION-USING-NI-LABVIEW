Hand Gesture Recognition - LabVIEW Vision System
Real-time vision-based gesture recognition using NI LabVIEW and camera input for human-computer interaction.

Overview
Built a gesture recognition system using LabVIEW's Vision Development Module that captures hand gestures through a webcam and processes them using computer vision algorithms for real-time classification and command execution.

Key Components
LabVIEW with Vision Development Module and NI-IMAQdx drivers

Camera system for live image acquisition

Vision processing, including edge detection, template matching, and pattern recognition

How It Works
System captures live video → converts to grayscale → applies Canny edge detection → extracts features using contour analysis → matches against stored gesture templates → outputs recognized gesture commands.

Applications
Human-computer interaction, accessibility solutions, touchless control systems, and assistive technology for deaf/dumb communication.
